## Project Description

C&A (Captivating Aroma) is a front-end perfume ordering website for a small perfume business. Customers can browse 60 perfume scents for women, men and everyone, search and filter by fragrance type, choose a 20ml or 50ml bottle, save favorites, and place an order for delivery or meetup. Before an order is placed, the website asks the customer to review their details so they can correct any mistakes in their name or address. The owner uses a separate admin page to view orders, search and filter them, and update each order's status. The project uses only HTML, CSS, JavaScript and JSON, with no backend or database. Orders and saved data are stored in the browser's Local Storage, so the admin page only shows orders placed in the same browser.

## Main Features
- One-page, scrollable customer website with a sticky navigation bar and smooth scrolling
- Perfume catalog of 60 products loaded from a JSON file
- Search by perfume name, and filters by category (Sweet, Floral, Fresh, Woody) and by gender (Women, Men, Unisex)
- Bottle size selection (20ml and 50ml) with live price updates
- Product details pop-up and unavailable-product messages
- Favorites that stay saved after refreshing the page
- Shopping cart with quantity controls, remove with confirmation, and automatic totals
- Checkout form with validation (name, mobile number, Facebook name or link, Delivery or Meetup, notes)
- "Are you sure you want to continue?" review pop-up before an order is placed
- Unique order reference number and order confirmation message
- Separate admin page with login, order totals by status, sales from completed orders, search, status filter, order details, and status updates
- Responsive design for phones, tablets and desktops

## Technologies Used
- HTML5
- CSS3 (custom properties, flexbox, grid, responsive layout)
- Vanilla JavaScript (ES6)
- JSON (product data)
- Fetch API
- Browser Local Storage (cart, favorites and orders) and Session Storage (admin session)
- Google Fonts (Cormorant Garamond and Jost)
- Visual Studio Code with the Live Server extension (development)
